# v0.10 最近活动与音视频基础预览设计

## 目标

在保持“本地优先、找资源最快”定位的前提下，分两个可独立发布的版本完成：

1. `v0.10.0`：把现有简单“最近资源”筛选升级为可筛选、可展开的最近活动时间线。
2. `v0.10.1`：在右侧详情面板加入音频与视频基础预览，并把真实开始播放记录为最近活动。

两个版本都不得删除、移动、重命名或修改原始素材文件，也不得向素材源目录写入转码、波形、缓存或元数据文件。

## 已确认决策

- 工作台采用“最近活动时间线 + 右侧音视频预览”的分工方式。
- 最近活动记录：
  - 打开文件。
  - 打开所在目录。
  - 复制路径。
  - 音频或视频预览。
- 历史保留最近 30 天，且全局最多保留最新 1,000 条。
- 同一资源的活动默认折叠，显示最后操作与动作摘要，可展开查看明细。
- 首批尝试预览格式：
  - 音频：MP3、WAV、OGG。
  - 视频：MP4、WebM。
- 播放使用原生 HTML 媒体控件，不做自定义播放条、音频波形、播放列表或后台播放。
- 切换资源时停止当前媒体；新资源不自动播放。
- 只有媒体实际触发 `play` 时才写入预览活动，选中资源不计入历史。

## 版本拆分

### v0.10.0 最近活动增强

交付完整的活动数据模型、清理规则、聚合查询、筛选、分页和时间线界面。

该版本继续保留现有三种动作记录，并为后续 `preview_media` 动作预留类型契约。即使 v0.10.1 尚未交付，v0.10.0 仍是完整、可测试、可发布的软件增量。

### v0.10.1 音视频基础预览

交付右侧详情媒体预览、播放生命周期、失败回退，并正式写入 `preview_media` 活动。

该版本复用 v0.10.0 的活动写入和时间线接口，不重新设计活动存储。

## 架构

保持现有分层：

```text
React components
  -> src/api/tauri.ts
  -> Tauri commands
  -> SQLite repository
```

最近活动由 Rust/SQLite 负责持久化、清理、聚合、过滤和分页。React 只负责查询条件、时间线展开状态、资源选择和展示。

音视频预览由 React 详情面板中的独立 `MediaPreview` 组件负责。组件使用 Tauri `convertFileSrc` 把绝对路径转换为 WebView 可读取的本地资源 URL，并使用原生 `<audio>` 或 `<video>` 元素播放。媒体不会被复制或转码。

## 数据模型

### 现有表扩展

继续使用 `recent_asset_actions`：

```text
id
asset_id
action_type
created_at
```

`action_type` 允许：

```text
open_file
reveal_folder
copy_path
preview_media
```

不另建“最近资源”表。每次活动保留独立记录，确保资源卡可以展开查看历史明细。

### 前端与后端类型

活动明细：

```ts
type RecentActivityAction = {
  id: number;
  action_type:
    | "open_file"
    | "reveal_folder"
    | "copy_path"
    | "preview_media";
  created_at: string;
};
```

按资源聚合的时间线条目：

```ts
type RecentActivityItem = {
  asset: Asset;
  latest_action_type: RecentActivityAction["action_type"];
  latest_action_at: string;
  action_count: number;
  open_file_count: number;
  reveal_folder_count: number;
  copy_path_count: number;
  preview_media_count: number;
  actions: RecentActivityAction[];
};
```

分页响应：

```ts
type RecentActivityResponse = {
  items: RecentActivityItem[];
  total_count: number;
  limit: number;
  offset: number;
};
```

### 缺失资源

活动查询关联现有 `assets` 记录。资源被标记 `is_missing` 时，活动仍保留并显示缺失状态。

删除资源库文件夹索引时，相关资源和活动按现有数据库外键级联删除。此操作只影响应用数据库，不影响磁盘源文件。

## 清理规则

活动写入后，以及应用启动数据库初始化完成后，执行同一个清理函数：

1. 删除 `created_at` 早于当前时间 30 天的活动。
2. 按 `created_at DESC, id DESC` 排序，仅保留最新 1,000 条。

清理必须在 SQLite 事务中完成。使用 `created_at` 和 `id` 作为稳定顺序，避免同一时间戳导致保留结果不确定。

活动清理失败不得阻止打开文件、定位目录、复制路径或媒体播放。业务动作成功后，活动记录属于辅助能力；记录失败由前端非阻塞记录日志，不把已成功的文件动作报告为失败。

## 最近活动查询

新增专用分页查询，不再把最近活动压缩成资源 ID 数组后拼接普通搜索结果。

请求：

```ts
type RecentActivityRequest = {
  period: "all" | "today" | "week";
  action_type:
    | "all"
    | "open_file"
    | "reveal_folder"
    | "copy_path"
    | "preview_media";
  limit: number;
  offset: number;
};
```

规则：

- `all` 仍受 30 天保留上限约束。
- `today` 使用本地日期当天零点作为下界。
- `week` 表示滚动最近 7 天，不使用自然周。
- 先按筛选条件过滤活动，再按资源聚合。
- 聚合项按 `latest_action_at DESC`、资源 ID 倒序稳定排序。
- `total_count` 是符合条件的去重资源数量，不是活动明细数量。
- 每个聚合项返回该资源在当前筛选范围内的活动明细，按时间倒序。
- 单个资源最多返回最新 50 条明细，避免一个高频资源撑大单页响应；计数字段仍统计筛选范围内的全部活动。
- `limit` 限制在 1 到 100。

## 最近活动界面

### 上下文侧栏

进入导航轨“最近”后，左侧显示：

- 时间范围：
  - 全部。
  - 今天。
  - 最近 7 天。
- 动作类型：
  - 全部。
  - 打开文件。
  - 打开所在目录。
  - 复制路径。
  - 媒体预览。

筛选变化后重置分页和时间线展开状态。

### 中央时间线

只有“最近”上下文使用活动时间线。资源库、类型、标签和集合继续使用现有虚拟资源网格。

每个活动卡显示：

- 资源类型图标。
- 文件名。
- 父目录或截断后的路径摘要。
- 最后动作及相对时间。
- 动作摘要，例如“预览 2 次 · 复制路径 1 次”。
- 收藏状态。
- 缺失状态。

交互：

- 单击卡片：选中资源，右侧显示普通详情。
- 再次单击已选卡片：保持选择，不折叠详情。
- 双击卡片：调用现有打开文件动作；缺失资源禁用。
- “展开明细”：只展开或收起该卡的活动明细，不改变资源选择。
- 分页采用“加载更多”，不一次渲染全部 1,000 条。

明细行显示动作名称和绝对时间。时间线卡默认折叠。

### 空状态

需要区分：

- 尚无活动。
- 当前时间范围无活动。
- 当前动作类型无活动。

空状态不提供“清空历史”入口，首版历史仅自动清理。

## 音视频预览

### 支持范围

按资源类型和扩展名同时判断：

```text
audio + mp3
audio + wav
audio + ogg
video + mp4
video + webm
```

扩展名在比较前统一转小写。

名单表示允许尝试播放，不保证文件内部编码一定被 Windows WebView2 解码。组件可以使用 `canPlayType()` 做提示性预判，但最终状态以媒体元素实际加载结果为准。

### MediaPreview 组件

组件职责：

- 根据资源类型渲染 `<audio controls>` 或 `<video controls>`。
- 使用 `preload="metadata"`，避免选中资源时主动加载完整文件。
- 视频限制在右侧详情预览区域内，使用 `object-fit: contain`。
- 音频显示类型图标、文件名和原生控件，不生成波形。
- 触发 `play` 时通知上层写入 `preview_media`。
- 触发 `error` 时显示明确失败状态。
- 切换资源或卸载时停止并释放当前媒体。

建议接口：

```ts
type MediaPreviewProps = {
  asset: Asset;
  onPlaybackStarted: (asset: Asset) => void;
};
```

### 播放生命周期

资源变化时：

1. 对旧媒体调用 `pause()`。
2. 移除或清空旧 `src`。
3. 调用 `load()` 重置媒体元素。
4. 新资源渲染为未播放状态。

新资源绝不自动播放。

### 预览活动去重语义

每次媒体元素从暂停状态进入播放并触发 `play`，记录一条 `preview_media`。

为防止 React 重渲染或同一次播放过程重复写入，组件按“资源 ID + 当前连续播放会话”去重：

- 同一次连续播放只记录一次。
- 暂停后再次播放，记录新活动。
- 播放结束后重新播放，记录新活动。
- 拖动进度、修改音量、缓冲恢复不新增活动。

活动写入失败不停止播放，只记录非阻塞错误。

### 错误回退

以下情况进入失败状态：

- 文件缺失。
- Tauri 本地资源 URL 无法加载。
- WebView2 不支持容器或编码。
- 媒体元素触发 `error`。

失败文案：

```text
当前文件或编码无法在应用内预览。
```

继续保留：

- 打开文件。
- 打开所在目录。
- 复制路径。
- 属性、备注、标签和集合操作。

不得尝试自动转码，也不新增 ffmpeg 依赖。

## Tauri 资源访问

媒体路径继续通过 Tauri 受限本地资源协议访问。`convertFileSrc` 用于把本地绝对路径转换为 WebView 可加载 URL。

实现阶段必须复查 `tauri.conf.json` 的 asset protocol scope。现有缩略图 scope 只覆盖应用缩略图缓存，媒体预览需要安全地允许已索引资源路径，不能直接放宽为全盘通配符。

推荐新增后端 command，由后端按资产 ID 查询数据库、确认资产存在且路径仍与索引一致，再返回可供前端转换或加载的路径。权限设计不得采用 `"**/*"` 或等价的无限制文件系统 scope。

若 Tauri 资源协议无法在不放宽全盘 scope 的前提下直接服务任意资源库文件，则实施阶段应采用受控 command/自定义协议按资产 ID 流式读取，而不是扩大文件系统权限。该技术选择必须在 v0.10.1 的实施计划第一项中用桌面原型验证。

## 错误处理

- 最近活动查询失败：显示时间线错误状态和重试按钮，不影响其他工作区。
- 单条活动写入失败：不撤销已经成功的用户动作。
- 清理失败：记录错误，下次启动或写入时重试。
- 活动关联资源缺失：显示缺失状态，不自动删除活动。
- 媒体加载失败：回退占位，不影响详情面板其他功能。
- 快速切换资源：旧媒体必须停止，旧媒体的延迟事件不得写入新资源的活动。

## 测试策略

### Rust 与 SQLite

- 接受四种活动类型，拒绝未知类型。
- 写入后能按资源聚合。
- 动作类型和时间范围筛选正确。
- `today` 使用本地日期边界。
- `week` 使用滚动 7 天边界。
- 聚合计数和展开明细一致。
- 同时间戳使用 ID 稳定排序。
- 清理删除 30 天前活动。
- 清理仅保留最新 1,000 条。
- 清理和写入事务失败时不产生半完成状态。
- 缺失资源活动仍可查询。
- 删除资源索引后活动按外键级联删除，源文件不受影响。
- 分页 `total_count` 使用去重资源数量。

### React

- 最近上下文切换到时间线，其他上下文仍显示网格。
- 时间范围和动作类型筛选正确组装请求。
- 活动卡显示最后动作、摘要、收藏和缺失状态。
- 展开明细不改变选择。
- 单击选择，双击打开。
- 缺失资源禁用打开与媒体播放。
- 加载更多追加条目并保持现有展开状态。
- 支持格式判断覆盖 MP3、WAV、OGG、MP4、WebM。
- 非目标格式继续显示类型占位。
- 音频与视频使用原生控件和 `preload="metadata"`。
- 切换资源暂停并重置旧媒体。
- 新资源不自动播放。
- 同一次连续播放只写入一次活动。
- 暂停后重新播放写入新活动。
- 媒体错误显示回退文案并保留文件动作。
- 旧媒体延迟事件不会记录到新资源。

### 桌面烟测

准备应用外测试素材目录，包含：

- 一个 MP3。
- 一个 WAV。
- 一个 OGG。
- 一个 MP4。
- 一个 WebM。
- 一个扩展名在名单内但编码不兼容的媒体文件。

验证：

- 五种目标格式均进入媒体预览尝试。
- 可解码文件能播放、暂停、拖动进度和调节音量。
- 不兼容编码显示失败回退。
- 切换资源立即停止旧媒体。
- 播放成功后时间线出现“媒体预览”。
- 仅选中资源不产生预览活动。
- 时间线筛选、折叠、明细和加载更多正常。
- 原始文件路径、内容、大小和修改时间不变。

## 不在范围内

- 音频波形生成。
- 自定义播放控件。
- 播放列表、播放队列或后台播放。
- 自动播放。
- 媒体转码。
- 音视频编辑、裁剪或导出。
- 字幕管理。
- 逐帧视频预览。
- PSD、Spine 或 3D 运行时预览。
- 手动清空活动历史。
- 云同步或跨设备历史。
