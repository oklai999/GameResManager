## Product Semantics

- 集合名保存前 `trim`，空名称拒绝。
- 集合名继续使用数据库唯一约束；重名错误通过现有 toast 错误通道显示。
- 集合描述保存前 `trim`，允许为空。
- 集合列表按名称排序，并显示当前成员数量。
- 删除集合前必须二次确认，文案明确“不会删除原始素材文件”。
- 删除当前选中的集合后，清空集合筛选和当前选择。
- “从当前集合移出”只在已经选中某个集合筛选且至少选中一个资源时显示。
- 批量加入和批量移出使用幂等 SQL；重复加入或移出不存在的成员不报错。

```rust
pub async fn update_collection(
    db: &Db,
    collection_id: i64,
    name: &str,
    description: &str,
) -> anyhow::Result<crate::models::Collection> {
    let name = name.trim();
    let description = description.trim();
    anyhow::ensure!(!name.is_empty(), "collection name cannot be empty");
    let now = chrono::Utc::now().to_rfc3339();

    let result = sqlx::query(
        "UPDATE collections
         SET name = ?1, description = ?2, updated_at = ?3
         WHERE id = ?4",
    )
    .bind(name)
    .bind(description)
    .bind(now)
    .bind(collection_id)
    .execute(db)
    .await?;
    anyhow::ensure!(result.rows_affected() == 1, "collection not found");

    sqlx::query_as::<_, crate::models::Collection>(
        "SELECT
           c.id,
           c.name,
           c.description,
           COUNT(ca.asset_id) AS asset_count
         FROM collections c
         LEFT JOIN collection_assets ca ON ca.collection_id = c.id
         WHERE c.id = ?1
         GROUP BY c.id, c.name, c.description",
    )
    .bind(collection_id)
    .fetch_one(db)
    .await
    .map_err(Into::into)
}

pub async fn remove_assets_from_collection(
    db: &Db,
    collection_id: i64,
    asset_ids: &[i64],
) -> anyhow::Result<()> {
    if asset_ids.is_empty() {
        return Ok(());
    }

    let mut tx = db.begin().await?;
    for asset_id in asset_ids {
        sqlx::query(
            "DELETE FROM collection_assets
             WHERE collection_id = ?1 AND asset_id = ?2",
        )
        .bind(collection_id)
        .bind(asset_id)
        .execute(&mut *tx)
        .await?;
    }
    sqlx::query(
        "UPDATE collections SET updated_at = ?1 WHERE id = ?2",
    )
    .bind(chrono::Utc::now().to_rfc3339())
    .bind(collection_id)
    .execute(&mut *tx)
    .await?;
    tx.commit().await?;
    Ok(())
}

pub async fn delete_collection(
    db: &Db,
    collection_id: i64,
) -> anyhow::Result<bool> {
    let result = sqlx::query("DELETE FROM collections WHERE id = ?1")
        .bind(collection_id)
        .execute(db)
        .await?;
    Ok(result.rows_affected() == 1)
}
```
