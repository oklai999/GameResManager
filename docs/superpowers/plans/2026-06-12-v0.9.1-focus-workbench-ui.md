# v0.9.1 聚焦工作台界面优化 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按“聚焦工作台”方向重构现有桌面界面，在保留全部功能的前提下减少常驻控件、突出资源网格，并提升搜索、筛选、预览和整理效率。

**Architecture:** 本版本只调整 React 组件、前端状态与 CSS，不修改 Rust command、SQLite schema 或搜索协议。主界面改为“窄导航轨 + 上下文侧栏 + 中央资源工作区 + 固定详情面板”；高级筛选进入可展开面板，生效条件以可移除标签回显，资源网格支持两档密度。

**Tech Stack:** Tauri 2, React 18, TypeScript, Vite, lucide-react, Vitest, Testing Library, CSS Grid.

## UX Decisions

1. 左侧使用 52px 导航轨切换“资源库、类型、标签、集合、最近、设置”。
2. 上下文侧栏默认展开，宽 220px；再次点击当前导航项可折叠，为资源网格释放空间。
3. 搜索栏常驻；搜索范围和数值/日期筛选进入“筛选”面板。
4. 已生效筛选显示为可移除标签，不要求用户重新打开面板才能理解当前结果。
5. 排序和网格密度保持常驻；不新增列表视图。
6. 详情面板保留右侧，但正文独立滚动，高频动作固定在底部。
7. 设置不再堆在资源库侧栏底部，进入独立“设置”上下文。
8. 不引入新后端能力、云功能、AI、删除、移动或重命名。

```tsx
import {
  Clock3,
  FolderKanban,
  Layers3,
  Settings,
  Shapes,
  Tags,
} from "lucide-react";

export type WorkbenchSection =
  | "library"
  | "types"
  | "tags"
  | "collections"
  | "recent"
  | "settings";

type Props = {
  activeSection: WorkbenchSection;
  sidebarOpen: boolean;
  onSelect: (section: WorkbenchSection) => void;
};

const items = [
  { id: "library", label: "资源库", icon: FolderKanban },
  { id: "types", label: "类型", icon: Shapes },
  { id: "tags", label: "标签", icon: Tags },
  { id: "collections", label: "集合", icon: Layers3 },
  { id: "recent", label: "最近", icon: Clock3 },
  { id: "settings", label: "设置", icon: Settings },
] satisfies Array<{
  id: WorkbenchSection;
  label: string;
  icon: typeof FolderKanban;
}>;

export function NavigationRail({ activeSection, sidebarOpen, onSelect }: Props) {
  return (
    <nav className="navigation-rail" aria-label="工作区导航">
      <div className="navigation-rail-brand" aria-label="游戏资源管理器">
        GR
      </div>
      <div className="navigation-rail-items">
        {items.map(({ id, label, icon: Icon }) => {
          const active = activeSection === id && sidebarOpen;
          return (
            <button
              key={id}
              type="button"
              className={active ? "rail-button active" : "rail-button"}
              aria-label={label}
              aria-pressed={active}
              title={label}
              onClick={() => onSelect(id)}
            >
              <Icon size={18} aria-hidden="true" />
            </button>
          );
        })}
      </div>
    </nav>
  );
}
```
