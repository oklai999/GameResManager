## 使用方式

- 推荐由一个总控 Agent 按 Task 90 → Task 96 顺序调度。
- 每次只把一个任务提示词交给一个执行 Agent。
- Task 90-95 会共同修改 `App.tsx` 和 `styles.css`，禁止并行执行。
- 后续任务开始前，必须确认前一任务的验证通过。
- 每个 Agent 只执行指定任务，不得提前做后续任务。
- 默认不要求 Agent 创建 Git 提交；由总控 Agent统一检查和提交。
- 视觉效果主要使用 React、CSS 和现有 Lucide 图标实现，不需要再次调用生图技能。
