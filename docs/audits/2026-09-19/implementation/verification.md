## 已完成

1. **范围与条件组合**：资源库、集合、类型、收藏、缺失分别保存；切换侧栏保留搜索范围。条件条显示所有上述条件和原有高级筛选，可单独移除或保留关键词清除条件。恢复中文片段与空格 AND 提示；零结果可加入路径范围、扩展至所有资源库。扫描及整理后刷新查询，加载和失败状态明确标注旧结果。
2. **原图快看**：选中图片卡片后空格、双击或详情按钮进入；适应窗口、100%、缩放、拖动、透明棋盘格、左右候选、Esc 和焦点恢复。只读取当前图片，候选来自已加载结果；不自动预读完整库。后端通过已索引 ID 读取，检查文件实际格式，限制 32 MiB、1600 万像素、解码分配 128 MiB，并限制同时读取数；转为内存 PNG，不落盘、不修改源文件。支持 PNG/JPEG/WebP/GIF 首帧/BMP，不支持 PSD 原图快看。
3. **使用与找回**：属性区复制各路径/名称与底部复制统一记录，仅剪贴板成功后写事件；原图加载成功才写 `preview_image`，选中不记事件。最近活动新增缩略图、全记录文件名/路径片段搜索和返回入口；同一会话保留查询、条件、排序、已加载候选、滚动位置和资源选择。收藏和备注同步更新最近活动详情。

新增迁移 `0010_image_preview_activity.sql` 保留既有事件并扩展 CHECK 值；沿用最近 30 天 / 1000 条保留规则。最近搜索按词 AND、名称或路径 OR，关键词是字面片段，分页前过滤；按活动中的资源 ID 查询，避免为每个关键词扫描整个资源表。

- 未进行万级/十万级素材库基准测试，不声称大库性能提升或给出耗时承诺。
