## What's New in v0.10.1

- **Native Media Preview**: Supported audio (`mp3`, `wav`, `ogg`) and video (`mp4`, `webm`) files now render native controls in the right inspector.
- **Restricted Media Protocol**: Media is served through the custom `asset-media` protocol by indexed asset ID only; URLs never expose the source file path.
- **Preview Activity Recording**: A `preview_media` recent-activity entry is recorded only when playback actually starts, once per continuous play session.
- **Codec/Load Failure Fallback**: When WebView2 cannot decode a media file, the inspector shows a clear fallback message while preserving open, reveal, copy-path, notes, tags, and collections.
- **Lifecycle Safety**: Switching selection stops and releases the old media element; there is no autoplay or background playback.
